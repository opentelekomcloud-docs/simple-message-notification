Exporting Topics
================

Scenarios
---------

You can export information about all topics under your account in an XLSX file to a local directory. This file records the topic name, ID, enterprise project, topic URN, creation time, and display name.

Procedure
---------

#. Log in to the management console.

#. In the upper left corner of the page, click |image1| and select the desired region and project.

#. Select **Application** > **Simple Message Notification**.

   The SMN console appears.

#. In the navigation pane, choose **Topics**.

   The **Topics** page appears.

#. Above the topic list, click **Export** to export topic information.

   The options are as follows:

   -  **Export all data to an XLSX file.**: Export information about all topics under the current account.
   -  **Export selected data to an XLSX file.**: Export information about the selected topics.

#. In the default download path, view the topic information.
