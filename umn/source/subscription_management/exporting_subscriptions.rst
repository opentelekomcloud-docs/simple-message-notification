Exporting Subscriptions
=======================

Scenarios
---------

You can export information about all subscriptions under your account in an XLSX file to a local directory. The file records the subscription URN, protocol, endpoint, status, request header, description, and topic name.

Procedure
---------

#. Log in to the management console.

#. In the upper left corner of the page, click |image1| and select the desired region and project.

#. Select **Application** > **Simple Message Notification**.

   The SMN console appears.

#. In the navigation pane on the left, choose **Subscriptions**.

   The **Subscription** page appears.

#. Above the subscription list, click **Export** to export subscription information.

   The options are as follows:

   -  **Export all data to an XLSX file.**: Export information about all subscriptions under the current account.
   -  **Export selected data to an XLSX file.**: Export information about the selected subscriptions.

#. In the default download path, view the subscription information.
