Deleting a Message Template
===========================

Scenarios
---------

This section describes how to delete a message template on the management console.

Procedure
---------

#. Log in to the management console.

#. In the upper left corner of the page, click |image1| and select the desired region and project.

#. Select **Application** > **Simple Message Notification**.

   The SMN console appears.

#. In the navigation pane on the left, choose **Message Templates**.

#. On the **Message Templates** page, locate the target template and click **Delete** in the **Operation** column.


   .. figure:: /_static/images/en-us_image_0000002624786890.png
      :alt: **Figure 1** Deleting a message template

      **Figure 1** Deleting a message template

#. Confirm the information about the message template to be deleted and enter **DELETE** or click **Auto Enter**.

#. Click **OK**.
